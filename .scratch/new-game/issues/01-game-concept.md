# Game concept

Type: research
Status: resolved

What game are we building?

Reference direction: an original reincarnation fantasy inspired by the feeling of “That Time I Got Reincarnated as a Tyrant God”: begin as an unknown or weak character, collect supernatural node abilities, and grow toward godlike power and authority.

Decision: build a top-down action RPG prototype focused on combat, exploration, and supernatural node collection. The first slice will use original characters, names, lore, and art. The player reincarnates as a weak vessel, defeats void creatures, collects node powers, and chooses upgrades while ascending toward godhood.
