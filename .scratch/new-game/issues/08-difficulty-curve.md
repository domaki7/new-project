# Difficulty curve

Type: prototype
Status: resolved

How should the action loop become challenging?

## Answer
Difficulty rises through pressure rather than arbitrary restrictions. The vessel starts with 85 vitality, enemies spawn faster, enemy health and speed scale more aggressively by wave, contact damage is harsher, leeches drain vitality more strongly, and splitter offspring are more dangerous. Node pickups and multi-weapon auto-casting remain the player's tools for surviving the curve.
