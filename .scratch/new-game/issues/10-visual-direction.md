# Visual direction

Type: prototype
Status: resolved

How should the game look and feel?

## Answer
Crown of the Absolute uses an original dark-fantasy royal visual language. The player is an armored crowned knight-like vessel, enemies are angular monster silhouettes with distinct colors and health bars, and node weapons appear as glowing diamond relics. The arena uses deep navy, teal, coral, and gold accents to suggest an emerging overlord rather than a generic sci-fi dashboard.
