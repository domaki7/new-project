# Powerup node pool

Type: prototype
Status: resolved

How should arena pickups differ from weapon nodes?

## Answer
The arena can spawn passive upgrade nodes alongside weapon nodes. Upgrade nodes include Executioner Rune, Blood Rune, Ward Rune, Gravity Rune, and Iron Rune. They are collected by proximity, immediately apply their permanent effect, and appear in the active build display without entering the auto-cast weapon loop.
