# Proximity pickup readability

Type: prototype
Status: resolved

How should floor weapons be readable during active combat?

## Answer
Distant relics use a restrained glow to limit arena clutter. When the vessel approaches within inspection range, the relic brightens, gains a thicker outline, and reveals a larger framed card with its full name and MELEE, RANGED, or UPGRADE category. The first guaranteed relic uses the same presentation and establishes the build path on collection.
