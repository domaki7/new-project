# Death meta progression

Type: prototype
Status: resolved

How should failure make the next attempt stronger?

## Answer
When the vessel dies, the run converts essence and level into persistent Crown Coins. The death screen exposes three permanent upgrades: Crown Edge increases starting weapon power, Throne of Iron increases starting vitality, and Sovereign Grasp increases node pickup range. Purchases persist in browser storage and apply to the next run; current-run weapons and essence still reset.
