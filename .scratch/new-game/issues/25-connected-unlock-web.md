# Connected unlock web

Type: prototype
Status: resolved

How should ascension choices remain connected?

## Answer
Ascension uses a family-specific node web. The current melee or ranged core is the root, weapon and upgrade nodes branch outward from it, owned nodes remain visible, locked nodes are dimmed, and only adjacent frontier nodes are selectable. The player chooses one connected unlock at each ascension and expands the build along that path.
