# Godot parity

Type: task
Status: resolved

What does “everything from the browser version, only better” mean for the Godot build?

## Answer
Godot is now the active engine implementation. It includes the browser version's major systems: top-down movement, unarmed first-relic path choice, melee/ranged weapon families, five-slot simultaneous auto-cast, weapon ranks, enemy variety and scaling, relic pickups, persistent Crown Coins, death upgrades, connected ascension state, restart, fullscreen scaling, dark-fantasy arena rendering, and a native HUD showing title, vitality, essence, wave, path, active weapons, and Crown Coins.

The browser prototype remains as a reference while Godot becomes the place for further development and desktop export.
